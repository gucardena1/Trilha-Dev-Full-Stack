6. PHP & Laravel

PHP básico

A linguagem que roda "nos bastidores" da maioria dos sites do mundo: o que ela faz, onde vive e como escrever suas primeiras linhas.

Analogia Pense num restaurante. Você (o navegador) senta na mesa e faz um pedido. O garçom leva esse pedido até a cozinha, e é lá — longe da sua vista — que a comida é de fato preparada. Você só recebe o prato pronto. O PHP é o "cozinheiro" que trabalha nessa cozinha escondida: ele roda no servidor (o computador que hospeda o site), prepara alguma coisa (busca dados, calcula um preço, monta uma página) e entrega o resultado já pronto para o seu navegador, que só sabe exibir HTML. Você nunca vê o código PHP rodando — só o prato final.

O que é PHP e por que ele existe

PHP é uma linguagem de programação de servidor. Isso significa que o código PHP não roda no seu navegador (como o JavaScript roda) — ele roda numa máquina remota, o servidor, antes de qualquer coisa chegar até você. O servidor executa o código PHP, monta uma página HTML (ou um JSON, ou um PDF, o que for necessário) e manda esse resultado já pronto pela internet até o seu navegador. O navegador nunca "vê" o PHP em si — só o resultado final.

Isso é diferente do JavaScript que você talvez já tenha visto: aquele roda direto no navegador do usuário. O PHP existe justamente para fazer o trabalho que precisa acontecer "escondido" — coisas que não podem depender do computador do usuário, como consultar um banco de dados, verificar uma senha, calcular o total de um carrinho de compras com preços que só o servidor conhece, ou gerar conteúdo diferente para cada visitante. PHP foi criado nos anos 90 e hoje move boa parte da internet: sites como Wikipedia, Facebook (nas origens) e milhões de sistemas administrativos e e-commerces são construídos com ele. É também a base sobre a qual o framework Laravel, que você vai estudar nas próximas lições, foi construído.

Como um arquivo PHP funciona

Um arquivo PHP normalmente tem a extensão .php e pode misturar HTML comum com trechos de código PHP. Tudo que está entre <?php e ?> é interpretado como código PHP; o resto é tratado como texto/HTML puro e enviado direto para o navegador. 

<?php
    $nome = "Maria";
?>

<!doctype html>
<html>
  <body>
    <h1>Olá, <?php echo $nome; ?>!</h1>
  </body>
</html>

Quando esse arquivo é acessado por um navegador, o servidor executa a parte PHP primeiro (define $nome e depois imprime seu valor no lugar certo), e o navegador recebe apenas o HTML final: <h1>Olá, Maria!</h1>. Se você "ver código-fonte" da página no navegador, nunca vai encontrar a palavra $nome ali — só o resultado.

Dica Para rodar PHP no seu computador, você precisa de um servidor local. As opções mais comuns são instalar o PHP diretamente e rodar php -S localhost:8000 na pasta do projeto, ou usar pacotes como XAMPP / Laragon, que já vêm com tudo configurado.

Variáveis

Em PHP, toda variável começa com o símbolo de cifrão $. Isso é uma marca registrada da linguagem — é fácil identificar uma variável PHP só de olhar. Não é preciso declarar o "tipo" da variável antes de usá-la; o PHP descobre sozinho se é um texto, um número, etc. 

<?php
$nome = "João";        // uma string (texto)
$idade = 28;            // um número inteiro
$altura = 1.75;         // um número decimal
$ativo = true;          // um booleano (verdadeiro/falso)

echo "Nome: $nome, idade: $idade anos";
// Repare que dentro de aspas duplas, o PHP substitui $nome e $idade
// pelos valores automaticamente. Isso se chama "interpolação de string".

O comando echo

echo é o comando mais usado em PHP: ele manda um texto (ou o valor de uma variável) direto para a saída, ou seja, para o que vai ser enviado ao navegador. É parecido com o console.log do JavaScript, só que em vez de aparecer no console de depuração, o resultado do echo vira parte da página HTML final. 

<?php
echo "Isso vai aparecer na página.";
echo "Você pode concatenar textos com ponto: " . "assim.";
$preco = 49.9;
echo "O produto custa R$ " . $preco;

Arrays

Um array em PHP é uma "caixa" que guarda várias informações organizadas. Pode ser uma lista simples (array indexado por números) ou um conjunto de pares chave-valor (array associativo, parecido com um objeto do JavaScript). 

<?php
// Array indexado (lista simples)
$frutas = ["maçã", "banana", "uva"];
echo $frutas[0]; // "maçã" — índices começam em 0

// Array associativo (chave => valor)
$usuario = [
    "nome" => "Ana",
    "email" => "ana@email.com",
    "idade" => 30
];
echo $usuario["nome"]; // "Ana"

// Percorrendo um array com foreach
foreach ($frutas as $fruta) {
    echo $fruta . "<br>";
}

Estruturas de controle

PHP tem as mesmas ferramentas lógicas de qualquer linguagem: condicionais e laços de repetição, com uma sintaxe parecida com JavaScript e Java. 

<?php
$idade = 20;

if ($idade >= 18) {
    echo "Maior de idade";
} else {
    echo "Menor de idade";
}

for ($i = 0; $i < 5; $i++) {
    echo "Número: $i <br>";
}

Funções

Funções em PHP funcionam como em quase toda linguagem: um bloco de código nomeado, que recebe parâmetros e pode devolver (return) um resultado. Servem para evitar repetir o mesmo código várias vezes. 

<?php
function calcularDesconto($preco, $percentual) {
    $desconto = $preco * ($percentual / 100);
    return $preco - $desconto;
}

$precoFinal = calcularDesconto(100, 10);
echo "Preço com desconto: $precoFinal"; // 90
Atenção Um erro muito comum de quem começa em PHP é esquecer o cifrão $ antes do nome da variável, ou esquecer o ponto e vírgula ; no fim da linha. O PHP é rígido com esses dois detalhes e vai mostrar um erro de sintaxe até você corrigir.

Um exemplo completo

Juntando tudo: um arquivo produtos.php que guarda uma lista de produtos num array e mostra cada um deles com seu preço, usando um laço foreach: 

<?php
$produtos = [
    ["nome" => "Teclado", "preco" => 150],
    ["nome" => "Mouse", "preco" => 60],
    ["nome" => "Monitor", "preco" => 900],
];

function formatarPreco($valor) {
    return "R$ " . number_format($valor, 2, ",", ".");
}
?>
<!doctype html>
<html>
<body>
  <h1>Nossos produtos</h1>
  <ul>
    <?php foreach ($produtos as $produto): ?>
      <li><?php echo $produto["nome"]; ?> — <?php echo formatarPreco($produto["preco"]); ?></li>
    <?php endforeach; ?>
  </ul>
</body>
</html>

Repare na sintaxe alternativa foreach (...): ... endforeach; — ela é muito usada quando se mistura PHP com HTML, porque fica mais legível do que usar chaves { } no meio de tags HTML. Você vai ver essa mesma ideia de "misturar lógica com marcação", só que de um jeito muito mais organizado, quando chegar ao Blade do Laravel, mais adiante nesta trilha.

Resumo

  • PHP é uma linguagem de servidor: roda no servidor antes da página chegar ao navegador do usuário.
  • Variáveis em PHP sempre começam com $ e não precisam declarar tipo.
  • echo envia texto ou valores para a saída da página.
  • Arrays podem ser listas simples (indexadas) ou associativas (chave => valor).
  • Funções organizam código reutilizável, recebendo parâmetros e podendo devolver um valor com return.
  • É comum misturar PHP e HTML no mesmo arquivo usando <?php ?>.
