5. SQL & Bancos de Dados

CRUD: SELECT, INSERT, UPDATE, DELETE

Os quatro comandos que resolvem 90% do que você precisa fazer num banco de dados no dia a dia.

Analogia Pense de novo no armário de fichas do consultório. No dia a dia, uma secretária só faz quatro tipos de ação com aquelas fichas: procurar uma ficha para consultar algo, criar uma ficha nova para um paciente que chegou, atualizar uma ficha existente (o telefone mudou) e jogar fora uma ficha que não é mais necessária. Em qualquer sistema que usa banco de dados — uma rede social, um banco, uma loja virtual — é basicamente isso que acontece por trás das telas: procurar, criar, atualizar e apagar dados. Essas quatro ações têm até um apelido conhecido no mundo da programação: CRUD (Create, Read, Update, Delete).

Em SQL, essas quatro ações correspondem a quatro comandos: INSERT (criar), SELECT (ler/buscar), UPDATE (atualizar) e DELETE (apagar). Vamos usar como exemplo a tabela clientes que já apareceu na lição anterior:

SELECT: buscando dados

SELECT é o comando mais usado do SQL — ele não altera nada, só lê os dados que já existem. A forma mais simples pede todas as colunas de todas as linhas de uma tabela: 

SELECT * FROM clientes;

O asterisco * significa "todas as colunas". Na prática, é mais comum (e mais eficiente) pedir só as colunas que você realmente precisa: 

SELECT nome, cidade FROM clientes;

Para filtrar quais linhas devem aparecer, usamos a cláusula WHERE — é ela que responde à pergunta "buscar o quê, exatamente?": 

SELECT * FROM clientes
WHERE cidade = 'Recife';
SELECT * FROM clientes
WHERE idade > 30;

Para ordenar o resultado, usamos ORDER BY (por padrão em ordem crescente; DESC inverte para decrescente): 

SELECT nome, idade FROM clientes
ORDER BY idade DESC;

E para limitar quantas linhas voltam — muito útil quando a tabela tem milhões de registros e você só quer "os 10 primeiros" — existe o LIMIT: 

SELECT nome, idade FROM clientes
ORDER BY idade DESC
LIMIT 10;

Repare na ordem: WHERE filtra, ORDER BY ordena, LIMIT corta a quantidade — nessa sequência. É praticamente assim que você vai escrever a maioria das consultas do dia a dia.

Dica Convenção comum: escrever palavras-chave do SQL (SELECT, FROM, WHERE...) em maiúsculas e nomes de tabelas/colunas em minúsculas. O SQL não exige isso, mas ajuda demais na hora de ler o código depois — inclusive o seu próprio código de semanas atrás.

INSERT: criando um registro novo

Para adicionar uma linha nova numa tabela, usamos INSERT INTO, informando as colunas e, em seguida, os valores na mesma ordem: 

INSERT INTO clientes (nome, email, cidade, idade)
VALUES ('Diego Alves', 'diego@email.com', 'Salvador', 25);

Note que a coluna id não aparece na lista — como vimos na lição anterior, a chave primária costuma ser gerada automaticamente pelo próprio banco, então você não precisa (e normalmente nem deve) informá-la manualmente.

UPDATE: alterando um registro existente

Para modificar dados que já existem, usamos UPDATE junto com SET (o que muda) e WHERE (quais linhas mudam): 

UPDATE clientes
SET cidade = 'Belo Horizonte'
WHERE id = 2;

Esse comando muda a cidade apenas do cliente cujo id é 2 (Bruno Lima). Dá para atualizar várias colunas de uma vez, separando por vírgula: 

UPDATE clientes
SET cidade = 'Belo Horizonte', idade = 35
WHERE id = 2;

DELETE: apagando um registro

Para remover uma linha, usamos DELETE FROM com WHERE indicando qual linha: 

DELETE FROM clientes
WHERE id = 3;

Isso remove definitivamente o cliente Carla Dias (id 3) da tabela.

Atenção Este é, sem exagero, um dos erros mais famosos (e mais dolorosos) da carreira de qualquer pessoa que trabalha com banco de dados: rodar UPDATE ou DELETE sem a cláusula WHERE. Sem WHERE, o comando afeta todas as linhas da tabela — ou seja, DELETE FROM clientes; apaga a tabela inteira, e UPDATE clientes SET cidade = 'Recife'; muda a cidade de todo mundo para Recife. Antes de rodar um UPDATE ou DELETE em produção, é uma boa prática rodar primeiro o mesmo filtro com um SELECT, para conferir exatamente quais linhas serão afetadas.

Combinando os quatro comandos numa rotina comum

Um fluxo típico de uso seria: um novo cliente se cadastra no site (INSERT), a tela de perfil dele busca os dados salvos (SELECT), ele edita o telefone (UPDATE) e, se decidir encerrar a conta, o registro é removido (DELETE). Praticamente qualquer sistema com "login e cadastro" que você já usou faz essas quatro operações por trás dos panos, dezenas de vezes por segundo.

Você também pode combinar filtros mais elaborados usando AND e OR dentro do WHERE: 

SELECT * FROM clientes
WHERE cidade = 'Recife' AND idade >= 18;

Isso retorna apenas clientes de Recife que também têm 18 anos ou mais — as duas condições precisam ser verdadeiras ao mesmo tempo.

Resumo

  • SELECT busca dados; use WHERE para filtrar, ORDER BY para ordenar e LIMIT para limitar a quantidade de linhas.
  • INSERT INTO tabela (colunas) VALUES (valores) cria uma linha nova.
  • UPDATE tabela SET coluna = valor WHERE ... altera linhas existentes.
  • DELETE FROM tabela WHERE ... remove linhas existentes.
  • Nunca rode UPDATE ou DELETE sem WHERE — sem ele, o comando afeta a tabela inteira.
