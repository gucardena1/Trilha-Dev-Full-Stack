1. Fundamentos & Lógica

Repetição: loops

Aprenda a fazer o computador repetir uma tarefa automaticamente, sem copiar e colar código.

Analogia Imagine que você trabalha numa fábrica de camisetas e sua tarefa é dobrar cada camiseta que sai da esteira. Você não escreve uma instrução nova para cada camiseta ("dobre a camiseta 1", "dobre a camiseta 2", "dobre a camiseta 3"...) — você segue uma única instrução repetida: "enquanto houver camiseta na esteira, dobre a próxima". Um loop (repetição) no código é exatamente essa ideia: uma instrução só, que o computador repete sozinho até que uma condição diga "pare".

Sem loops, para exibir os números de 1 a 5 você teria que escrever cinco linhas quase idênticas. Com um loop, você escreve a regra uma única vez e o computador se encarrega de repetir. 

// Sem loop (funciona, mas não escala — imagine ir até 1000!)
console.log(1);
console.log(2);
console.log(3);
console.log(4);
console.log(5);

O loop for

O for é o loop mais usado quando sabemos, de antemão, quantas vezes queremos repetir algo (ou temos uma regra clara de início, fim e passo). Sua estrutura tem três partes separadas por ponto e vírgula: 

for (let i = 1; i <= 5; i++) {
  console.log(i);
}
// Mostra: 1, 2, 3, 4, 5

As três partes do for são:

  1. Inicialização (let i = 1): cria uma variável contadora, executada uma única vez, no começo.
  2. Condição (i <= 5): checada antes de cada repetição. Enquanto for verdadeira, o loop continua.
  3. Incremento (i++): executado ao final de cada repetição. i++ é um jeito curto de escrever i = i + 1.

A variável i (de "índice") funciona como um contador que a fábrica de camisetas usaria para saber "quantas camisetas eu já dobrei". A cada volta do loop, o JavaScript checa se i ainda satisfaz a condição; se sim, executa o bloco de código de novo; se não, para e segue em frente no programa.

Atenção O erro mais perigoso com loops é o loop infinito: quando a condição nunca se torna falsa, o computador fica repetindo para sempre (ou até travar o navegador). Isso costuma acontecer quando você esquece de atualizar a variável contadora, ou escreve a condição errada. Exemplo de loop infinito por engano: for (let i = 1; i > 0; i++) — a condição i > 0 nunca vai deixar de ser verdadeira, então nunca para.

O loop while

O while ("enquanto") é útil quando você não sabe de antemão quantas vezes vai repetir — você só sabe a condição que precisa continuar sendo verdadeira. É a estrutura mais próxima da frase "enquanto houver camiseta na esteira, dobre a próxima": 

let saldo = 100;
let gastos = 0;

while (saldo > 0) {
  gastos = gastos + 20;
  saldo = saldo - 20;
  console.log("Saldo restante: " + saldo);
}
// Mostra: 80, 60, 40, 20, 0 — e para porque saldo deixou de ser > 0

Repare que, diferente do for, o while não tem uma sintaxe pronta para "inicializar" ou "incrementar" — você é responsável por atualizar as variáveis manualmente dentro do bloco, senão corre o risco de criar um loop infinito.

Variação: do...while

Existe também o do...while, que executa o bloco pelo menos uma vez antes de checar a condição — útil, por exemplo, para pedir uma senha ao usuário pelo menos uma vez antes de validar: 

let tentativas = 0;

do {
  tentativas++;
  console.log("Tentativa número " + tentativas);
} while (tentativas < 3);
// Mostra: "Tentativa número 1", "2", "3" — sempre roda ao menos uma vez

Percorrendo listas com for

Um dos usos mais comuns de loop é percorrer todos os itens de uma lista (que na próxima lição você vai conhecer formalmente como array). Por enquanto, veja o padrão: 

let frutas = ["maçã", "banana", "uva"];

for (let i = 0; i < frutas.length; i++) {
  console.log(frutas[i]);
}
// Mostra: maçã, banana, uva

Note que o índice começa em 0, não em 1 — em quase todas as linguagens de programação, listas são "indexadas a partir de zero". Isso significa que o primeiro item de frutas é frutas[0], o segundo é frutas[1], e assim por diante. A propriedade .length devolve quantos itens a lista tem (nesse caso, 3), e por isso a condição do loop é i < frutas.length — se fosse i <= frutas.length, o loop tentaria acessar uma posição que não existe.

Dica Existe uma forma mais moderna e legível de percorrer listas, o for...of, que evita ter que lidar manualmente com índices: 
for (const fruta of frutas) {
  console.log(fruta);
}
// Mesmo resultado, sem precisar de "i" nem de frutas[i]
Use for...of sempre que só precisar do valor de cada item, e o for tradicional quando precisar também saber a posição (índice) de cada item.

Interrompendo um loop antes da hora: break e continue

Às vezes você quer sair de um loop antes de ele terminar naturalmente, ou pular uma repetição específica sem interromper tudo. Para isso existem duas palavras-chave: 

// break: para o loop completamente
for (let i = 1; i <= 10; i++) {
  if (i === 5) {
    break; // sai do loop assim que i chega a 5
  }
  console.log(i);
}
// Mostra: 1, 2, 3, 4

// continue: pula só esta repetição e vai para a próxima
for (let i = 1; i <= 5; i++) {
  if (i === 3) {
    continue; // pula o número 3, mas o loop continua
  }
  console.log(i);
}
// Mostra: 1, 2, 4, 5

Resumo

  • Loops repetem um bloco de código automaticamente, evitando escrever a mesma instrução várias vezes.
  • for é ideal quando você sabe (ou consegue calcular) quantas vezes repetir; tem inicialização, condição e incremento.
  • while repete enquanto uma condição for verdadeira, sem uma sintaxe fixa de contador.
  • Listas são indexadas a partir de zero, e .length devolve a quantidade de itens.
  • Cuidado com loops infinitos: sempre garanta que a condição eventualmente se torne falsa.
  • break interrompe o loop inteiro; continue pula só a repetição atual.
