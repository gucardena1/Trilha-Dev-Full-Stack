1. Fundamentos & Lógica

Variáveis, tipos e operadores

Aprenda a guardar informações na memória do computador e a fazer contas e comparações com elas.

Analogia Pense numa variável como uma caixa de guardados com uma etiqueta colada na frente. Você pode escrever "idade" na etiqueta e colocar o número 25 dentro da caixa. Mais tarde, se quiser trocar o conteúdo, você abre a mesma caixa e troca o que está lá dentro por outra coisa — a etiqueta continua a mesma, só o conteúdo muda. É exatamente assim que uma variável funciona: um espaço na memória do computador, com um nome, guardando um valor que pode mudar ao longo do programa.

Criando variáveis em JavaScript

Em JavaScript, criamos uma variável com a palavra let (quando o valor pode mudar depois) ou const (quando o valor nunca vai mudar depois de criado). Veja: 

let idade = 25;        // pode ser alterada depois
const nome = "Ana";    // não pode ser reatribuída depois de criada

console.log(idade);    // mostra: 25
console.log(nome);     // mostra: Ana

idade = 26;            // ok, "let" permite trocar o valor
// nome = "Beatriz";   // erro! "const" não permite reatribuir

Repare que o nome da variável fica à esquerda do sinal de igual, e o valor que ela vai guardar fica à direita. Esse sinal de igual não significa "igual" como na matemática — significa "atribua este valor a esta caixa". É uma das confusões mais comuns no início: em programação, = é uma ação (guardar), não uma afirmação (comparar). Para comparar valores, usamos outro operador, que você vai ver mais adiante.

Dica Use const como padrão. Só troque para let quando você realmente souber que o valor vai precisar mudar (como um contador, ou o placar de um jogo). Isso evita bugs bobos causados por uma variável que foi alterada sem querer em algum lugar do código.

Tipos de dados

Nem toda informação é do mesmo "tipo". O número 25 se comporta de um jeito (dá para somar, subtrair, multiplicar); o texto "Ana" se comporta de outro jeito (dá para juntar com outro texto, contar quantas letras tem); e existe também o tipo que representa apenas "verdadeiro" ou "falso". Os tipos mais básicos de qualquer linguagem de programação são:

TipoExemploPara que serve
Número (number)25, 3.14, -10Quantidades, idades, preços, cálculos.
Texto (string)"Ana", "Rua das Flores"Nomes, mensagens, qualquer texto entre aspas.
Booleano (boolean)true, falseRepresenta "sim ou não", "ligado ou desligado".
Indefinido (undefined)undefinedUma variável que existe mas ainda não recebeu valor.

Nas próximas lições você vai conhecer também os tipos compostos — arrays (listas) e objetos — que servem para agrupar vários valores relacionados numa única variável.

Atenção Texto sempre vai entre aspas (simples 'assim' ou duplas "assim", tanto faz, desde que combinem no início e no fim). Se você escrever let nome = Ana; sem aspas, o JavaScript vai achar que "Ana" é o nome de outra variável que não existe, e vai dar erro.

Operadores aritméticos

São os símbolos usados para fazer contas com números:

let a = 10;
let b = 3;

console.log(a + b);   // 13  (soma)
console.log(a - b);   // 7   (subtração)
console.log(a * b);   // 30  (multiplicação)
console.log(a / b);   // 3.333... (divisão)
console.log(a % b);   // 1   (resto da divisão, chamado de "módulo")

O operador % (módulo) costuma parecer estranho no início, mas é muito usado: ele devolve o resto de uma divisão. Por exemplo, 10 % 3 é 1, porque 10 dividido por 3 dá 3 inteiro e sobra 1. Esse operador é a base de truques como "descobrir se um número é par" (numero % 2 será 0 quando o número for par).

Concatenando textos

O sinal de + também funciona com textos, mas em vez de somar, ele junta (isso se chama concatenação): 

let nome = "Ana";
let saudacao = "Olá, " + nome + "!";
console.log(saudacao); // Olá, Ana!

// Forma mais moderna e legível: template strings, com crase (`)
let saudacao2 = `Olá, ${nome}!`;
console.log(saudacao2); // Olá, Ana!

As template strings (com crase ` em vez de aspas) permitem inserir variáveis diretamente dentro do texto usando ${nomeDaVariavel}, o que deixa o código muito mais fácil de ler quando você está montando frases com vários valores misturados.

Operadores de comparação

Para comparar dois valores (e descobrir se algo é verdadeiro ou falso), usamos operadores diferentes do sinal de atribuição:

OperadorSignificadoExemplo
===igual a (compara valor e tipo)5 === 5 → true
!==diferente de5 !== 3 → true
>maior que5 > 3 → true
<menor que5 < 3 → false
>=maior ou igual5 >= 5 → true
<=menor ou igual5 <= 4 → false

Note o uso de === (três sinais de igual) para comparar, em vez de apenas um =. Em JavaScript, um único = é sempre atribuição (guardar valor); três sinais === é sempre comparação (verificar se é igual). Usar só dois sinais (==) também funciona, mas ele é menos rigoroso e pode causar comportamentos inesperados — por isso a recomendação forte é sempre usar === e !==.

Dica Um jeito de nunca mais confundir: leia = como "recebe" ("idade recebe 25") e === como "é igual a" ("idade é igual a 25?"). Essa leitura em voz alta ajuda a evitar o erro mais clássico de quem está começando.

Operadores lógicos

Quando você precisa combinar mais de uma condição, usa operadores lógicos: && (E — as duas condições precisam ser verdadeiras), || (OU — pelo menos uma precisa ser verdadeira) e ! (NÃO — inverte o valor). 

let idade = 20;
let temCarteira = true;

console.log(idade >= 18 && temCarteira); // true (as duas são verdadeiras)
console.log(idade >= 18 || temCarteira); // true (pelo menos uma é verdadeira)
console.log(!temCarteira);               // false (inverteu o valor)

Esses operadores lógicos vão ser essenciais na próxima lição, sobre condicionais (if/else), porque é ali que usamos essas comparações para decidir qual caminho o programa deve seguir.

Resumo

  • Variáveis são "caixas com etiqueta" que guardam valores na memória; use let quando o valor muda e const quando não muda.
  • Os tipos básicos são número, texto (string), booleano (true/false) e undefined.
  • Operadores aritméticos (+ - * / %) fazem contas; o + em textos concatena em vez de somar.
  • Um único = atribui valor; === compara valores — não confunda os dois.
  • Operadores lógicos (&&, ||, !) combinam condições e serão a base dos condicionais.
