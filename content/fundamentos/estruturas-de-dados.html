1. Fundamentos & Lógica

Arrays, listas e objetos

Aprenda a agrupar vários valores relacionados numa única variável, de duas formas diferentes.

Analogia Um array é como uma fileira numerada de caixinhas de correio num prédio: caixinha 0, caixinha 1, caixinha 2... cada uma guarda uma coisa, e você acessa pelo número da posição. Um objeto é diferente: é como uma ficha de cadastro, onde cada informação tem um rótulo em vez de um número — "nome: Ana", "idade: 25", "cidade: Recife". Você não pergunta "o que tem na posição 2 da ficha?", você pergunta "qual é o valor do campo idade?". Os dois servem para guardar vários valores juntos, mas organizam esses valores de formas diferentes — e você escolhe um ou outro dependendo do que faz mais sentido para os dados que está representando.

Arrays: listas ordenadas

Um array guarda vários valores em ordem, acessados por um índice numérico que sempre começa em 0 (como você já viu na lição sobre loops): 

const frutas = ["maçã", "banana", "uva"];

console.log(frutas[0]); // maçã (primeiro item)
console.log(frutas[1]); // banana
console.log(frutas[2]); // uva
console.log(frutas.length); // 3 (quantidade de itens)

Repare que usamos const, mesmo sabendo que vamos alterar o conteúdo da lista mais adiante. Isso não é uma contradição: const impede que a variável frutas passe a apontar para outro array inteiro, mas o conteúdo interno do array ainda pode ser modificado normalmente (adicionar, remover ou alterar itens).

Métodos comuns de array

Arrays vêm com funções prontas (chamadas de métodos) para as operações mais comuns do dia a dia: 

const numeros = [10, 20, 30];

numeros.push(40);        // adiciona no final: [10, 20, 30, 40]
numeros.pop();           // remove o último item: [10, 20, 30]
numeros.unshift(5);      // adiciona no início: [5, 10, 20, 30]
numeros.shift();         // remove o primeiro item: [10, 20, 30]

console.log(numeros.includes(20)); // true (a lista contém 20?)
console.log(numeros.indexOf(30));  // 2 (em que posição está o 30?)
Dica Três métodos de array que você vai usar o tempo todo em código real são map (transforma cada item da lista e devolve uma lista nova), filter (devolve só os itens que passam num teste) e forEach (executa uma ação para cada item, sem devolver nada novo): 
const precos = [10, 20, 30];

const comDesconto = precos.map((preco) => preco * 0.9);
console.log(comDesconto); // [9, 18, 27]

const maioresQueVinte = precos.filter((preco) => preco > 20);
console.log(maioresQueVinte); // [30]

precos.forEach((preco) => console.log(`Preço: R$ ${preco}`));
// Preço: R$ 10 / Preço: R$ 20 / Preço: R$ 30
Note que esses métodos recebem uma função como argumento — isso é totalmente normal em JavaScript: funções podem ser passadas de um lado para o outro, assim como um número ou um texto.

Objetos: dados com rótulo

Um objeto agrupa informações relacionadas usando pares de chave (o rótulo) e valor (o dado em si): 

const pessoa = {
  nome: "Ana",
  idade: 25,
  cidade: "Recife",
};

console.log(pessoa.nome);     // Ana
console.log(pessoa.idade);    // 25
console.log(pessoa["cidade"]); // Recife (forma alternativa de acessar)

Existem duas formas de acessar um valor dentro de um objeto: com ponto (pessoa.nome), que é a mais comum e legível, ou com colchetes e o nome entre aspas (pessoa["nome"]), útil quando o nome da chave está guardado em uma variável, ou quando o nome da chave tem espaços ou caracteres especiais.

Alterando e adicionando propriedades

const pessoa = { nome: "Ana", idade: 25 };

pessoa.idade = 26;         // altera um valor existente
pessoa.profissao = "Dev";  // adiciona uma propriedade nova

console.log(pessoa);
// { nome: "Ana", idade: 26, profissao: "Dev" }
Atenção Assim como nos arrays, um objeto criado com const ainda permite alterar seus valores internos — o que const proíbe é substituir o objeto inteiro por outro (pessoa = {} daria erro). Isso costuma confundir iniciantes, que acham que const "trava tudo" — na verdade, ele trava apenas a variável em si, não o conteúdo dela quando esse conteúdo é um array ou objeto.

Combinando os dois: listas de objetos

Na prática, o padrão mais comum em aplicações reais é uma lista de objetos — por exemplo, uma lista de produtos de uma loja, cada um com seu próprio nome, preço e estoque: 

const produtos = [
  { nome: "Caneta", preco: 2.5, estoque: 100 },
  { nome: "Caderno", preco: 15.0, estoque: 30 },
  { nome: "Mochila", preco: 89.9, estoque: 5 },
];

// Percorrendo a lista e acessando propriedades de cada objeto:
for (const produto of produtos) {
  console.log(`${produto.nome}: R$ ${produto.preco} (estoque: ${produto.estoque})`);
}

// Filtrando com os métodos que já vimos:
const emFalta = produtos.filter((produto) => produto.estoque < 10);
console.log(emFalta); // [{ nome: "Mochila", preco: 89.9, estoque: 5 }]

Esse padrão — array de objetos — é exatamente como dados costumam chegar de um banco de dados ou de uma API (assunto que você vai ver mais à frente na trilha): uma lista de "registros", cada um com os mesmos campos, mas valores diferentes. Dominar como ler, percorrer e filtrar esse tipo de estrutura é uma das habilidades mais usadas no dia a dia de quem programa.

Arrays e objetos podem se aninhar

Um objeto pode conter um array, um array pode conter objetos, um objeto pode conter outro objeto — essa flexibilidade é o que permite representar informações complexas do mundo real: 

const usuario = {
  nome: "Carlos",
  enderecos: [
    { rua: "Rua A", numero: 100 },
    { rua: "Rua B", numero: 200 },
  ],
};

console.log(usuario.enderecos[0].rua); // Rua A
console.log(usuario.enderecos[1].numero); // 200

Para acessar um dado "aninhado" (dentro de outro), você simplesmente encadeia o acesso: primeiro entra no array enderecos, depois escolhe a posição ([0]), depois acessa a propriedade desse objeto específico (.rua). Vá com calma nesses casos: leia da esquerda para a direita, um passo de cada vez.

Resumo

  • Arrays guardam listas ordenadas de valores, acessadas por índice numérico começando em 0.
  • Objetos guardam dados com rótulo (chave: valor), acessados por nome em vez de posição.
  • Métodos como push, map, filter e forEach facilitam operações comuns em arrays.
  • const impede reatribuir a variável inteira, mas não impede alterar o conteúdo interno de um array ou objeto.
  • Listas de objetos são o padrão mais comum para representar dados reais (produtos, usuários, registros de um banco de dados).
  • Arrays e objetos podem se aninhar (um dentro do outro) para representar informações mais complexas.
