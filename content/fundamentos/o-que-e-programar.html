1. Fundamentos & Lógica

O que é programar?

Entenda, sem jargão nenhum, o que realmente acontece quando alguém "programa" um computador.

Analogia Imagine que você está ensinando sua avó a fazer um bolo pelo telefone. Ela nunca fez esse bolo antes e vai seguir exatamente o que você disser — nem mais, nem menos. Se você disser "misture os ingredientes", ela vai travar, porque isso é vago demais: quais ingredientes? Em que ordem? Por quanto tempo? Você precisa dizer passo a passo: "pegue 2 ovos", "quebre-os numa tigela", "adicione 200g de farinha", "misture por 1 minuto". Programar é exatamente isso: escrever uma receita tão detalhada e tão precisa que até alguém (ou algo) sem nenhum bom senso próprio consegue seguir e chegar ao resultado certo.

O computador é essa "avó" no telefone — só que muito mais literal e muito mais rápido. Ele não tem intuição, não "entende" o que você quis dizer, não preenche lacunas. Ele executa exatamente o que está escrito, na ordem em que está escrito, milhões de vezes por segundo se for preciso. Programar é o ato de escrever essas instruções numa linguagem que o computador consegue interpretar sem ambiguidade.

Um programa é uma sequência de instruções

Todo programa, por mais complexo que pareça — um jogo, um aplicativo de banco, uma rede social — é, no fundo, uma sequência enorme de instruções simples, executadas em ordem. As instruções básicas que qualquer linguagem de programação oferece são poucas:

  • Guardar informação (ex: guardar o nome do usuário, o valor de um produto).
  • Fazer contas (somar, subtrair, comparar valores).
  • Tomar decisões ("se isso acontecer, faça aquilo; senão, faça outra coisa").
  • Repetir ações (fazer a mesma coisa várias vezes, sem reescrever o código todo).
  • Organizar tudo em blocos reutilizáveis (as famosas funções).

As próximas lições desta trilha vão te ensinar exatamente essas cinco coisas, uma de cada vez. Elas são o alfabeto da programação — depois que você domina esse alfabeto, qualquer linguagem (JavaScript, Python, PHP, o que for) vira só uma questão de vocabulário e sintaxe diferentes para as mesmas ideias.

Do código até a tela

Você escreve o código num arquivo de texto simples — o computador não entende português nem inglês, ele entende apenas sinais elétricos (ligado/desligado, 0 e 1). Entre o que você escreve e o que o processador executa existe um programa tradutor, chamado compilador ou interpretador, dependendo da linguagem. Ele pega seu texto e transforma em instruções que o hardware consegue rodar. Você não precisa entender os detalhes disso agora — só precisa saber que existe essa "ponte" e que é por isso que precisamos instalar programas específicos (como o Node.js, para rodar JavaScript fora do navegador) para executar código.

Seu primeiro programa

Nesta trilha vamos usar principalmente JavaScript para os exemplos, porque ele roda em qualquer navegador sem precisar instalar nada — basta abrir as ferramentas de desenvolvedor do navegador (tecla F12) e digitar na aba "Console". O programa mais clássico de todos manda o computador exibir uma mensagem: 

// Isto é um comentário: o computador ignora tudo depois de //
// Serve só para humanos lerem e entenderem o código.

console.log("Olá, mundo!");
// Isso manda o computador escrever "Olá, mundo!" na tela (no console).

Repare em três coisas importantes nesse exemplo pequeno: primeiro, o comando console.log(...) é uma instrução que já vem pronta na linguagem JavaScript, pedindo para "mostrar algo na tela". Segundo, o texto "Olá, mundo!" está entre aspas — isso diz ao computador "isto é um texto literal, não é um comando". Terceiro, a linha termina com ponto e vírgula ;, que é como dizemos "fim da instrução", parecido com o ponto final de uma frase.

Dica Toda linguagem de programação tem sua versão do "Olá, mundo!" — é o exemplo tradicional para testar se o ambiente está funcionando. Quando você for aprender uma linguagem nova, esse costuma ser o primeiro passo.

Programar é resolver problemas, não decorar comandos

Um erro comum de quem está começando é achar que programar é decorar uma lista enorme de comandos. Na prática, o comando em si é a parte mais fácil — você pode procurar a sintaxe exata a qualquer momento. A parte difícil (e a que realmente importa) é pensar em como quebrar um problema do mundo real em passos que o computador consiga seguir. Por exemplo: "calcular o troco de uma compra" parece simples para uma pessoa, mas para o computador você precisa detalhar: pegar o valor pago, pegar o valor total, subtrair um do outro, e mostrar o resultado. Esse tipo de raciocínio — transformar uma tarefa vaga em passos exatos — é o que chamamos de lógica de programação, e é o assunto central de toda esta primeira trilha.

Atenção Não se preocupe se, no começo, você sentir que "não pensa como programador". Ninguém nasce pensando assim — é uma habilidade que se desenvolve com prática, exatamente como aprender a dirigir ou tocar um instrumento. As primeiras semanas são as mais estranhas; depois, o raciocínio lógico começa a virar automático.

O que vem a seguir

Nas próximas lições você vai aprender a guardar informações em variáveis, a fazer o computador tomar decisões, a repetir tarefas automaticamente e a organizar tudo isso em blocos reutilizáveis chamados funções. Ao final desta trilha, você já vai conseguir ler e escrever pequenos programas que resolvem problemas reais — e vai ter a base lógica necessária para aprender HTML, CSS, JavaScript "de verdade" e qualquer outra linguagem no resto da trilha Full Stack.

Resumo

  • Programar é escrever instruções extremamente precisas para que o computador execute exatamente o que você quer.
  • Todo programa é feito de poucos blocos básicos: guardar dados, fazer contas, tomar decisões, repetir ações e organizar código em funções.
  • O computador não entende português: existe um tradutor (compilador/interpretador) entre o seu código e o hardware.
  • console.log("texto") é o comando mais simples do JavaScript para exibir algo na tela.
  • A parte mais importante de programar não é decorar comandos, é desenvolver a lógica para quebrar problemas em passos simples.
