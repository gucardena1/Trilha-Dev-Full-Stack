2. HTML & CSS

CSS: seletores e box model

Como pintar, vestir e espaçar os elementos que o HTML já construiu.

Analogia Se o HTML é o esqueleto da casa — paredes, cômodos, portas — o CSS é a decoração: a cor da tinta, o tipo de piso, a distância entre o sofá e a parede. CSS significa Cascading Style Sheets, "folhas de estilo em cascata". "Cascata" porque as regras escorrem de cima para baixo e podem se sobrepor, de um jeito bem previsível — você vai entender esse efeito ao longo da lição.

Como aplicar CSS a uma página

Existem três formas de ligar CSS a um HTML, da menos recomendada à mais recomendada:

FormaComo funcionaQuando usar
InlineAtributo style direto na tagQuase nunca — difícil de manter.
InternoTag <style> dentro do <head>Testes rápidos, páginas únicas e pequenas.
ExternoArquivo .css separado, ligado com <link>Padrão em qualquer projeto real.
<!-- Inline: evite, exceto para testes rápidos -->
<p style="color: red;">Texto vermelho</p>

<!-- Interno: dentro do head -->
<head>
  <style>
    p { color: red; }
  </style>
</head>

<!-- Externo: forma recomendada -->
<head>
  <link rel="stylesheet" href="estilos.css" />
</head>

No arquivo .css externo, cada regra segue o mesmo formato: um seletor (o que vai ser estilizado), seguido de chaves com uma ou mais declarações, cada uma no formato propriedade: valor;. 

p {
  color: red;
  font-size: 18px;
}
Dica Nunca esqueça o ponto e vírgula no fim de cada declaração. É um dos erros mais silenciosos: o navegador às vezes ignora a linha seguinte sem avisar nada, e você fica procurando um erro que na verdade é só um ; faltando.

Seletores: escolhendo o que estilizar

O seletor é a parte antes das chaves, e existem vários tipos. Os três mais usados no dia a dia:

SeletorSintaxeSeleciona
Tagp { }Todos os elementos <p> da página.
Classe.destaque { }Todo elemento com class="destaque", podem repetir.
ID#titulo-principal { }O único elemento com id="titulo-principal", não repete na página.
<p class="destaque">Este parágrafo tem uma classe.</p>
<p id="titulo-principal">Este tem um ID.</p>
.destaque {
  background-color: yellow;
}

#titulo-principal {
  font-weight: bold;
}

Pense em classe como uma etiqueta reutilizável — vários elementos podem usar class="destaque" — e em ID como um nome próprio, único, que só um elemento na página pode ter. Uma boa regra prática: use classes na grande maioria das vezes; reserve IDs para casos bem específicos (como um link interno de âncora na página).

Cores e fontes

Cores podem ser escritas de várias formas em CSS:

h1 {
  color: red;               /* nome da cor */
  color: #ff0000;           /* hexadecimal */
  color: rgb(255, 0, 0);    /* vermelho, verde, azul */
}

Fontes são controladas por font-family (a fonte em si), font-size (tamanho) e font-weight (peso, de fino a negrito):

body {
  font-family: Arial, sans-serif;
  font-size: 16px;
  font-weight: normal;
}

h1 {
  font-weight: bold;
}
Dica Sempre coloque uma segunda opção de fonte depois da primeira, como Arial, sans-serif. Se o computador de quem visita não tiver a fonte "Arial" instalada, ele cai para qualquer fonte "sans-serif" (sem serifa) disponível, em vez de usar uma fonte totalmente diferente do que você planejou.

O box model: todo elemento é uma caixa

Aqui está talvez a ideia mais importante do CSS: todo elemento HTML é, por baixo dos panos, uma caixa retangular. Mesmo que pareça redondo ou irregular na tela, o espaço que ele ocupa é sempre um retângulo. Esse conceito se chama box model (modelo de caixa), e ele tem quatro camadas, de dentro para fora:

Analogia Pense numa caixa de presente. O content é o presente em si. O padding é o papel de seda amassado ao redor dele, para proteger e dar espaço. O border é a própria caixa de papelão. E o margin é o espaço vazio entre essa caixa e as outras caixas de presente ao lado dela, para elas não se encostarem.
CamadaO que é
contentO conteúdo em si: o texto, a imagem.
paddingEspaço interno, entre o conteúdo e a borda da caixa.
borderA borda visível (ou não) ao redor da caixa.
marginEspaço externo, entre esta caixa e as caixas vizinhas.
.cartao {
  width: 300px;
  padding: 20px;
  border: 2px solid #333;
  margin: 16px;
}
Erro comum Confundir margin com padding é quase um rito de passagem de quem está aprendendo CSS. A forma mais fácil de lembrar: padding empurra o conteúdo para dentro da própria caixa (aumenta o "colchão" interno); margin empurra as outras caixas para longe da caixa atual (aumenta a distância externa). Se você quer mais espaço entre dois blocos, geralmente é margin que você quer.

Cada uma dessas propriedades aceita valores separados por lado, e também um atalho para os quatro lados de uma vez: 

/* Um valor: aplica aos 4 lados */
padding: 10px;

/* Dois valores: vertical horizontal */
padding: 10px 20px;

/* Quatro valores: topo direita baixo esquerda (sentido horário) */
padding: 10px 20px 10px 20px;

/* Um lado específico */
padding-left: 24px;
margin-top: 8px;

Unidades de medida

Escolher a unidade certa importa bastante para o resultado ficar consistente:

UnidadeO que significaQuando usar
pxPixels, um tamanho fixo e absoluto.Bordas finas, detalhes que não devem mudar de tamanho.
%Porcentagem do elemento pai.Larguras flexíveis que se adaptam ao espaço disponível.
remMúltiplo do tamanho de fonte da página (raiz), geralmente 16px.Tamanhos de fonte e espaçamentos, respeita configurações de acessibilidade do usuário.
vh / vwPorcentagem da altura/largura da janela do navegador.Seções que devem ocupar a tela inteira, como um banner de topo.
Dica Prefira rem para tamanhos de fonte em vez de px. Se a pessoa que visita o site aumentar o tamanho de fonte padrão do navegador (algo comum entre pessoas com baixa visão), textos em rem crescem junto; textos em px ficam travados no mesmo tamanho.

box-sizing: um detalhe que evita dor de cabeça

Por padrão, quando você define width: 300px, o CSS soma o padding e a border por cima disso — a caixa final acaba maior que 300px. Isso costuma pegar iniciantes de surpresa. A correção padrão da indústria é uma única linha no topo do CSS: 

* {
  box-sizing: border-box;
}

Com border-box, o width passa a incluir o padding e a border dentro dele — a caixa final tem exatamente a largura que você definiu, o que é bem mais intuitivo.

Exemplo completo

<style>
  * {
    box-sizing: border-box;
  }

  .cartao {
    width: 320px;
    padding: 16px;
    margin: 20px;
    border: 1px solid #ccc;
    background-color: #f5f5f5;
    font-family: Arial, sans-serif;
  }

  .cartao h2 {
    color: #333;
    font-size: 1.2rem;
  }
</style>

<div class="cartao">
  <h2>Título do cartão</h2>
  <p>Um pequeno texto de exemplo dentro da caixa.</p>
</div>

Resumo

  • CSS estiliza o que o HTML já estruturou; prefira sempre um arquivo .css externo.
  • Seletores de tag, classe (.nome) e ID (#nome) escolhem o que será estilizado.
  • Todo elemento é uma caixa: content, padding, border e margin, de dentro para fora.
  • padding empurra o conteúdo para dentro; margin empurra outros elementos para fora.
  • rem é a melhor escolha para fontes; % e vh/vw para layouts flexíveis.
  • box-sizing: border-box evita surpresas com o tamanho final dos elementos.
