2. HTML & CSS

Flexbox e Grid

As duas ferramentas modernas para organizar elementos no espaço, sem gambiarra.

Analogia Pense em organizar móveis numa sala. Flexbox é como arrumar pessoas em uma fila única, para tirar uma foto: você decide se ficam lado a lado ou em pé uma atrás da outra, e como distribuir o espaço sobrando entre elas. Grid é como desenhar uma grade de estacionamento no chão primeiro, com vagas numeradas em linhas e colunas, e só depois encaixar os carros dentro de cada vaga. Uma organiza em uma direção só; a outra organiza nas duas direções ao mesmo tempo.

Por que não usar apenas o CSS "tradicional"

Antes do Flexbox e do Grid existirem, alinhar caixas lado a lado ou centralizar algo verticalmente em CSS era famoso por ser complicado, cheio de truques (como usar float ou posicionamento manual). Flexbox (2013) e Grid (2017) foram criados especificamente para resolver layout de forma direta e previsível. Hoje em dia, são a forma padrão de organizar qualquer página.

Flexbox: organizando em uma linha ou coluna

Flexbox trabalha com um elemento pai, que vira o "container flexível", e seus filhos diretos, que se organizam ao longo de um eixo — horizontal ou vertical. Para ativar, basta uma linha no elemento pai: 

.container {
  display: flex;
}

Só essa linha já coloca todos os filhos diretos lado a lado, na horizontal, por padrão. A partir daí, algumas propriedades no container controlam como esses filhos se distribuem:

PropriedadeFaz o quê
flex-directionDireção do eixo: row (linha, padrão) ou column (coluna).
justify-contentAlinhamento ao longo do eixo principal: flex-start, center, space-between, space-around.
align-itemsAlinhamento no eixo cruzado (perpendicular): flex-start, center, stretch.
gapEspaço fixo entre os itens, sem precisar de margin manual em cada um.
<style>
  .menu {
    display: flex;
    justify-content: space-between;
    align-items: center;
    gap: 16px;
  }
</style>

<nav class="menu">
  <a href="#">Início</a>
  <a href="#">Produtos</a>
  <a href="#">Contato</a>
</nav>

Esse exemplo é praticamente o caso de uso número um do Flexbox: um menu de navegação com os links espalhados horizontalmente, com space-between empurrando o primeiro item para a esquerda e o último para a direita.

Dica Centralizar algo vertical e horizontalmente ao mesmo tempo era um pesadelo no CSS antigo. Com Flexbox, é só isto: 
.container {
  display: flex;
  justify-content: center;
  align-items: center;
  height: 100vh;
}

Controlando os filhos individualmente

Além das propriedades no pai, cada filho pode receber flex-grow (o quanto ele cresce para ocupar espaço sobrando) e flex-shrink (o quanto ele encolhe se faltar espaço). O atalho mais comum é a propriedade flex, que combina as duas: 

.coluna-principal {
  flex: 2; /* ocupa 2 partes do espaço disponível */
}
.barra-lateral {
  flex: 1; /* ocupa 1 parte */
}

Grid: organizando em linhas e colunas ao mesmo tempo

Enquanto o Flexbox pensa em uma única fileira (que pode quebrar linha, mas ainda é pensado item a item), o Grid pensa a página inteira como uma grade — como uma planilha, com linhas e colunas definidas de antemão. Também começa com uma linha no elemento pai: 

.container {
  display: grid;
}

A propriedade mais importante do Grid é grid-template-columns, que define quantas colunas existem e o tamanho de cada uma:

.galeria {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  gap: 16px;
}

A unidade fr ("fraction", fração) representa uma parte do espaço disponível. 1fr 1fr 1fr cria três colunas de larguras iguais. Se você quisesse uma coluna lateral fixa e o resto flexível, poderia escrever grid-template-columns: 250px 1fr; — uma coluna de exatos 250px e outra que ocupa todo o espaço restante. 

<style>
  .pagina {
    display: grid;
    grid-template-columns: 250px 1fr;
    gap: 24px;
  }
</style>

<div class="pagina">
  <aside>Menu lateral</aside>
  <main>Conteúdo principal</main>
</div>

Uma ferramenta muito prática do Grid é a função repeat(), que evita repetir 1fr várias vezes, e auto-fit combinado com minmax(), que cria colunas responsivas automaticamente, sem precisar de media queries: 

.galeria {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  /* equivalente a: 1fr 1fr 1fr */
}

.galeria-responsiva {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
  /* cria quantas colunas de no mínimo 200px couberem na tela */
  gap: 16px;
}

Flexbox ou Grid: quando usar cada um

Essa é a dúvida mais comum de quem já conhece as duas ferramentas. A resposta curta: Flexbox para uma dimensão, Grid para duas dimensões.

SituaçãoMelhor escolha
Menu de navegação horizontalFlexbox
Centralizar um elemento na telaFlexbox
Lista de botões que quebram linha naturalmenteFlexbox (com flex-wrap: wrap)
Layout geral da página: cabeçalho, menu lateral, conteúdo, rodapéGrid
Galeria de fotos em grade uniformeGrid
Cartões de produtos com alturas e larguras alinhadas em linhas e colunasGrid
Dica Na prática, os dois convivem no mesmo projeto sem problema: é comum usar Grid para o esqueleto geral da página (as grandes áreas) e Flexbox dentro de cada uma dessas áreas (para alinhar botões, ícones e textos). Um não substitui o outro — eles se complementam.
Erro comum Esquecer que display: flex ou display: grid só afeta os filhos diretos do elemento. Um neto (filho de um filho) não é organizado automaticamente pelo Flexbox ou Grid do avô — cada nível de aninhamento precisa da sua própria configuração, se for o caso.

Exemplo completo: página com Grid e Flexbox juntos

<style>
  .pagina {
    display: grid;
    grid-template-columns: 220px 1fr;
    grid-template-rows: auto 1fr;
    min-height: 100vh;
  }

  .cabecalho {
    grid-column: 1 / 3; /* ocupa as duas colunas */
    display: flex;
    justify-content: space-between;
    align-items: center;
    padding: 16px;
    background: #222;
    color: white;
  }

  .menu-lateral {
    background: #f0f0f0;
    padding: 16px;
  }

  .conteudo {
    padding: 16px;
  }
</style>

<div class="pagina">
  <header class="cabecalho">
    <strong>Minha Loja</strong>
    <nav style="display: flex; gap: 12px;">
      <a href="#">Início</a>
      <a href="#">Carrinho</a>
    </nav>
  </header>

  <aside class="menu-lateral">Categorias</aside>

  <main class="conteudo">Produtos aqui</main>
</div>

Repare que grid-column: 1 / 3 faz o cabeçalho ocupar da primeira até (sem incluir) a terceira linha de grade — ou seja, as duas colunas inteiras. Já dentro do cabeçalho, usamos Flexbox para alinhar o logo e o menu horizontalmente. Essa combinação é exatamente o padrão que você vai ver na maioria dos sites profissionais.

Resumo

  • Flexbox organiza itens em uma única direção (linha ou coluna); ative com display: flex.
  • justify-content, align-items e gap controlam alinhamento e espaçamento no Flexbox.
  • Grid organiza itens em linhas e colunas ao mesmo tempo; ative com display: grid.
  • grid-template-columns com a unidade fr define o tamanho das colunas.
  • Regra geral: Flexbox para uma dimensão, Grid para duas — e os dois costumam trabalhar juntos.
  • display: flex/grid afeta só os filhos diretos, não os netos.
