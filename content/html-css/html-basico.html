2. HTML & CSS

HTML: a estrutura da página

Como marcar título, parágrafo, lista, link e imagem — os tijolos de qualquer página da web.

Analogia Pense em construir uma casa. Antes de escolher a cor da parede ou o tipo de sofá, alguém precisa erguer o esqueleto: onde fica a porta, onde ficam as janelas, onde fica cada cômodo. O HTML é exatamente esse esqueleto de uma página web. Ele não decide se algo é bonito ou colorido — isso é trabalho do CSS, que você vai ver nas próximas lições. O HTML só diz "aqui vai um título", "aqui vai um parágrafo de texto", "aqui vai uma foto". Sem esqueleto, não tem onde pendurar a decoração.

O que é HTML, afinal?

HTML significa HyperText Markup Language — "linguagem de marcação de hipertexto". "Marcação" é a palavra chave: HTML não é uma linguagem de programação como Python ou JavaScript, que dizem ao computador "faça isso, depois aquilo". HTML apenas marca pedaços de texto dizendo o que cada um significa: isto é um título, isto é uma lista, isto é um link para outra página.

Essa marcação é feita com tags (etiquetas), que ficam entre os sinais de menor e maior: <p>, <h1>, <a>. Quase toda tag vem em par: uma de abertura, <p>, e uma de fechamento, com uma barra, </p>. Tudo que fica entre a abertura e o fechamento é o "conteúdo" daquele elemento. 

<p>Isto é um parágrafo de texto.</p>
Erro comum Esquecer de fechar uma tag é o erro número um de quem está começando. Escrever <p>Olá mundo sem o </p> final pode até "funcionar" visualmente em alguns casos, mas confunde o navegador sobre onde um elemento termina e o outro começa, e pode bagunçar todo o layout mais abaixo na página. Sempre feche o que você abriu.

A estrutura mínima de um documento HTML

Todo arquivo HTML segue um esqueleto padrão. Ele parece burocrático no início, mas cada parte tem um papel claro: 

<!doctype html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8" />
  <title>Minha primeira página</title>
</head>
<body>
  <h1>Olá, mundo!</h1>
  <p>Esta é minha primeira página HTML.</p>
</body>
</html>
  • <!doctype html> — a primeira linha, sempre. Avisa o navegador "isto aqui é HTML5, moderno, interprete assim".
  • <html> — a "caixa" que envolve a página inteira. O atributo lang="pt-BR" diz que o conteúdo está em português do Brasil, o que ajuda leitores de tela e o Google a entenderem o idioma.
  • <head> — a parte que não aparece visualmente na página. É os "bastidores": o título da aba do navegador, links para arquivos de estilo (CSS), configurações. Pense nela como a área técnica de um teatro, que o público não vê.
  • <body> — tudo que realmente aparece na tela: textos, imagens, botões, links. É o palco onde a peça acontece.

head vs. body: o bastidor e o palco

Uma confusão comum de quem começa é colocar conteúdo visível dentro do <head>. Isso não vai gerar um erro visível de cara, mas o navegador simplesmente ignora ou trata errado esse conteúdo, porque o <head> não foi feito para exibir nada. Guarde a regra: tudo que a pessoa que visita o site precisa ver ou ler vai dentro do <body>.

Elementos de texto

Dentro do <body>, os elementos mais usados para organizar texto são os títulos e os parágrafos.

Existem 6 níveis de título, de <h1> (o mais importante, geralmente único por página) até <h6> (o menos importante). Pense neles como os títulos e subtítulos de um documento do Word: o <h1> é o título do capítulo, o <h2> é uma seção dentro dele, o <h3> uma subseção, e assim por diante. 

<h1>Receitas de bolo</h1>
<h2>Bolo de chocolate</h2>
<p>Um bolo simples e delicioso para o café da tarde.</p>
<h3>Ingredientes</h3>
<p>Farinha, açúcar, ovos, chocolate em pó.</p>

Além de <p>, existem tags para dar ênfase dentro de um texto:

  • <strong> — deixa o texto em negrito e sinaliza que é importante.
  • <em> — deixa o texto em itálico, indicando ênfase.
  • <br /> — quebra de linha, sem criar um novo parágrafo. É uma das poucas tags que não tem fechamento, porque não tem conteúdo dentro dela.

Links: a tag <a>

A tag <a> (de "anchor", âncora) é o que transforma texto ou imagem em um link clicável. O endereço de destino vai no atributo href ("hypertext reference"). 

<a href="https://www.google.com">Ir para o Google</a>

<!-- Link para outra página do mesmo site -->
<a href="contato.html">Fale conosco</a>

<!-- Link que abre em nova aba -->
<a href="https://www.google.com" target="_blank">Abrir em nova aba</a>
Dica Um atributo é uma informação extra que você coloca dentro da tag de abertura, sempre no formato nome="valor". href é um atributo da tag <a>. Cada tag tem seu próprio conjunto de atributos possíveis — você vai aprender os mais importantes ao longo da trilha.

Imagens: a tag <img>

Para mostrar uma imagem, usamos <img>. Repare que ela não tem tag de fechamento — assim como <br>, ela não "envolve" nenhum conteúdo, apenas exibe um arquivo. 

<img src="gato.jpg" alt="Gato laranja dormindo no sofá" />

Dois atributos são essenciais aqui: src ("source", a origem) aponta para o caminho do arquivo de imagem, e alt descreve o que a imagem mostra em texto. O alt aparece se a imagem não carregar, e é lido em voz alta por leitores de tela usados por pessoas com deficiência visual — vamos falar mais sobre isso na próxima lição.

Listas

HTML tem duas famílias principais de listas. Ambas usam o mesmo item interno, <li> ("list item"), mudando apenas a tag que envolve tudo:

TagTipo de listaQuando usar
<ul>Não ordenada (com marcadores)A ordem dos itens não importa: ingredientes, itens de um menu.
<ol>Ordenada (numerada)A ordem importa: passo a passo de uma receita, um ranking.
<ul>
  <li>Leite</li>
  <li>Ovos</li>
  <li>Farinha</li>
</ul>

<ol>
  <li>Misture os ingredientes secos</li>
  <li>Adicione os ovos e o leite</li>
  <li>Leve ao forno por 40 minutos</li>
</ol>
Erro comum Colocar texto solto dentro de um <ul> ou <ol> sem envolvê-lo em <li>. Todo item de lista precisa estar dentro do seu próprio <li>—caso contrário o navegador pode exibir o conteúdo de forma estranha ou fora do lugar.

Comentários

Assim como em outras linguagens, você pode deixar anotações no código que o navegador ignora completamente, úteis para lembrar você mesmo (ou outra pessoa) do porquê de algo estar ali: 

<!-- Isto é um comentário e não aparece na página -->

Juntando tudo em um exemplo completo

<!doctype html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8" />
  <title>Página sobre bolos</title>
</head>
<body>
  <h1>Meu blog de receitas</h1>
  <p>Bem-vindo! Aqui você encontra receitas simples de bolo.</p>

  <h2>Bolo de cenoura</h2>
  <img src="bolo-cenoura.jpg" alt="Bolo de cenoura com cobertura de chocolate" />
  <p>Um clássico <strong>infalível</strong> da cozinha brasileira.</p>

  <h3>Ingredientes</h3>
  <ul>
    <li>3 cenouras</li>
    <li>4 ovos</li>
    <li>2 xícaras de açúcar</li>
  </ul>

  <p>Veja também nossa <a href="bolo-chocolate.html">receita de bolo de chocolate</a>.</p>
</body>
</html>

Repare como cada tag tem um papel único e previsível. Depois de entender essas peças básicas, ler qualquer página HTML do mundo fica muito mais simples: você reconhece os blocos, mesmo que o site pareça complexo por fora.

Resumo

  • HTML marca a estrutura e o significado do conteúdo, não a aparência — isso é papel do CSS.
  • Todo documento tem <html>, <head> (bastidor) e <body> (o que aparece).
  • Tags normalmente vêm em pares de abertura e fechamento; sempre feche o que abrir.
  • <h1> a <h6> são títulos; <p> é parágrafo.
  • <a href="..."> cria links; <img src="..." alt="..."> exibe imagens.
  • <ul>/<ol> com <li> criam listas não ordenadas e ordenadas.
