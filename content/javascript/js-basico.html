3. JavaScript

JS básico: variáveis, funções e DOM

Como dar vida a uma página HTML estática: guardar informação, tomar decisões e reagir ao que o usuário faz.

Para que serve o JavaScript?

Se o HTML é o esqueleto de uma página e o CSS é a roupa e a maquiagem, o JavaScript (JS) é o sistema nervoso: é ele que faz a página perceber o que acontece (um clique, uma tecla apertada, o carregamento terminar) e reagir a isso. Sem JS, uma página é uma foto. Com JS, ela vira um aplicativo de verdade.

JavaScript é a única linguagem de programação que roda nativamente dentro de todos os navegadores. Por isso ela é tão importante: não importa se o site foi feito em Vue, Laravel ou WordPress — no fim, o que roda no navegador do usuário é JavaScript.

Analogia Imagine uma loja de roupas. O HTML é a prateleira e as araras (a estrutura: onde fica cada coisa). O CSS é a vitrine, a iluminação e a organização visual (o visual). O JavaScript é o vendedor: ele repara quando você pega uma peça, te oferece um provador, calcula o desconto no caixa e te avisa quando o produto que você queria chegou. Ele é a parte "viva" da loja.

Como colocar JavaScript numa página HTML

Existem três formas principais. As duas primeiras você vai ver bastante em projetos reais:

1. Arquivo externo (a forma recomendada) — separa o HTML do comportamento, como já fazemos com CSS:

<!-- No final do <body>, pouco antes de fechar -->
<script src="script.js"></script>
</body>

2. Script inline, direto no HTML — útil para testes rápidos, mas evite em projetos maiores:

<script>
  console.log("Olá, isso roda assim que a página carrega esse trecho!");
</script>

3. Atributo de evento direto na tag — funciona, mas é considerado uma prática antiga (mistura estrutura com comportamento):

<button onclick="alert('Oi!')">Clique aqui</button>
Dica Coloque a tag <script> no final do <body>, e não no <head>. Assim o navegador já desenhou toda a página antes de rodar o JavaScript, evitando erros do tipo "elemento não encontrado" porque o script tentou procurar algo que ainda não existia na tela.

Variáveis: caixas com nome para guardar informação

Uma variável é um espaço na memória do computador que guarda um valor, e que tem um nome para você conseguir usá-lo depois. Em JavaScript moderno, usamos let para valores que podem mudar e const para valores que não vão mudar depois de definidos. 

let idade = 28;           // um número, pode mudar
const nome = "Marina";    // um texto (string), não muda
let ativo = true;         // um booleano: true ou false

idade = 29; // isso funciona, "let" permite reatribuição
// nome = "Outro"; // isso daria erro, "const" não permite

Os tipos básicos (chamados de "tipos primitivos") mais usados são:

  • String — texto, sempre entre aspas: "olá" ou 'olá'
  • Number — números, inteiros ou com casas decimais: 10, 3.14
  • Boolean — verdadeiro ou falso: true, false
  • Array — uma lista de valores: ["maçã", "banana", "uva"]
  • Object — um conjunto de informações relacionadas: { nome: "Ana", idade: 30 }
Pegadinha comum Existe também o var, a forma antiga de criar variáveis. Evite usá-la em código novo: ela tem um comportamento de "escopo" confuso que causa bugs difíceis de rastrear. Vamos entender exatamente por quê na lição de ES6+.

Funções: blocos de ação reutilizáveis

Uma função é uma receita: um bloco de código com um nome, que você pode "chamar" (executar) sempre que precisar, quantas vezes quiser, sem reescrever tudo de novo. 

function saudar(nome) {
  return "Olá, " + nome + "!";
}

console.log(saudar("Carlos")); // "Olá, Carlos!"
console.log(saudar("Ana"));    // "Olá, Ana!"

nome aqui é um parâmetro: uma informação que a função recebe de fora para poder trabalhar. E return é o valor que a função devolve para quem a chamou.

Manipulando o DOM: alterando a página em tempo real

O DOM (Document Object Model) é a representação da sua página HTML na memória do navegador, organizada como uma árvore de elementos. O JavaScript consegue "conversar" com essa árvore: encontrar elementos, ler o que tem neles e mudá-los.

A ferramenta mais usada para encontrar um elemento é o querySelector, que aceita os mesmos seletores que você já usa no CSS:

<p id="mensagem">Texto original</p>
<button id="botao">Mudar texto</button>

<script>
  const paragrafo = document.querySelector("#mensagem");
  const botao = document.querySelector("#botao");
</script>

Depois de encontrar o elemento, você pode ler ou alterar seu conteúdo e aparência:

paragrafo.textContent = "Texto novo!";       // troca o texto
paragrafo.classList.add("destaque");         // adiciona uma classe CSS
paragrafo.classList.remove("escondido");     // remove uma classe
paragrafo.classList.toggle("ativo");         // liga/desliga uma classe
paragrafo.style.color = "blue";              // muda o estilo diretamente

E para reagir a uma ação do usuário — um clique, por exemplo — usamos addEventListener, que "escuta" um evento e executa uma função quando ele acontece: 

botao.addEventListener("click", function () {
  paragrafo.textContent = "Você clicou no botão!";
  paragrafo.classList.add("destaque");
});

Isso é o núcleo de praticamente toda interatividade na web: encontrar um elemento, escutar um evento nele, e alterar algo na tela quando o evento acontece.

Analogia Pense no querySelector como apontar o dedo para uma pessoa específica numa sala cheia de gente ("aquela ali, com a camisa azul"). O addEventListener é combinar com essa pessoa: "quando você levantar a mão, me avisa" — e o que você faz quando ela avisa é a função que você passou.

Um exemplo completo

<p id="contador">Cliques: 0</p>
<button id="btn-contar">Clique em mim</button>

<script>
  let cliques = 0;
  const textoContador = document.querySelector("#contador");
  const botaoContar = document.querySelector("#btn-contar");

  botaoContar.addEventListener("click", function () {
    cliques = cliques + 1;
    textoContador.textContent = "Cliques: " + cliques;
  });
</script>

Repare que cliques precisa ser let, porque seu valor muda a cada clique. Já os elementos que buscamos com querySelector podem ser const, porque a referência ao elemento em si não muda — só o que está dentro dele.

Dica Abra o console do navegador (tecla F12, aba "Console") sempre que estiver aprendendo. É lá que aparecem erros, e é onde console.log(...) imprime valores para você "espiar" o que está acontecendo dentro do seu código.

Resumo

  • JavaScript é a linguagem que dá interatividade às páginas web, rodando dentro do navegador.
  • Prefira incluir JS em um arquivo externo com <script src="..."> no final do <body>.
  • Use let para variáveis que mudam e const para as que não mudam; evite var.
  • Funções são blocos de código reutilizáveis que podem receber parâmetros e devolver (return) um valor.
  • document.querySelector() encontra um elemento no DOM; addEventListener() reage a eventos nele.
  • textContent, classList e style são as formas mais comuns de alterar um elemento pelo JS.
