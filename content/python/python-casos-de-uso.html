8. Python

Scripts, automação e dados

Onde o Python realmente brilha no mercado de trabalho — e por que ele virou a "faca suíça" de quem programa.

Você já viu a sintaxe e a orientação a objetos em Python. Agora vamos falar do que importa na prática: para que as empresas realmente usam Python no dia a dia. Ele é usado para construir sites (com Django ou Flask), para ciência de dados e inteligência artificial, mas o uso mais comum — e o mais subestimado por quem está aprendendo — é como ferramenta de automação e scripts.

Analogia Pense num escritório onde alguém, toda sexta-feira, baixa uma planilha, renomeia arquivos, copia números de um sistema para outro e manda um e-mail com o resumo. Isso leva 40 minutos manuais, toda semana, o ano inteiro. Python é a pessoa que você contrata uma vez para aprender a fazer exatamente essa tarefa — e depois ela faz em 3 segundos, sempre do mesmo jeito, sem reclamar e sem errar por cansaço.

Automação de tarefas repetitivas

Esse é o caso de uso número um do Python no mercado, especialmente fora de empresas de tecnologia: analistas, contadores, profissionais de RH e marketing usam Python para automatizar tarefas manuais e repetitivas que consomem horas todo mês.

Um exemplo simples: renomear em lote todos os arquivos de uma pasta.

import os

pasta = "./relatorios"

for nome_arquivo in os.listdir(pasta):
    if nome_arquivo.endswith(".txt"):
        novo_nome = nome_arquivo.replace(" ", "_").lower()
        caminho_antigo = os.path.join(pasta, nome_arquivo)
        caminho_novo = os.path.join(pasta, novo_nome)
        os.rename(caminho_antigo, caminho_novo)
        print(f"Renomeado: {nome_arquivo} -> {novo_nome}")

import os traz o módulo os, parte da biblioteca padrão do Python (já vem instalada, não precisa baixar nada). Ele dá acesso a funções que conversam com o sistema operacional: listar arquivos de uma pasta, criar diretórios, renomear e apagar arquivos, e muito mais.

Dica A biblioteca padrão do Python é enorme e cobre boa parte do que você precisa sem instalar nada extra: os e shutil para arquivos, datetime para datas, csv para planilhas simples, json para dados estruturados, re para busca de padrões em texto (expressões regulares). Antes de instalar uma biblioteca externa, vale checar se a biblioteca padrão já resolve.

Scripts de linha de comando

Outro uso muito comum: pequenos programas que rodam no terminal, recebem entradas do usuário (ou de argumentos) e produzem um resultado — sem precisar de interface gráfica nenhuma. É o formato favorito para ferramentas internas de equipes de desenvolvimento. 

# arquivo: conversor.py
def celsius_para_fahrenheit(celsius):
    return celsius * 9 / 5 + 32

def main():
    entrada = input("Digite a temperatura em Celsius: ")
    celsius = float(entrada)
    fahrenheit = celsius_para_fahrenheit(celsius)
    print(f"{celsius}°C equivale a {fahrenheit}°F")

if __name__ == "__main__":
    main()
$ python3 conversor.py
Digite a temperatura em Celsius: 30
30.0°C equivale a 86.0°F

input() pausa o programa e espera o usuário digitar algo, devolvendo sempre uma string — por isso a conversão com float().

E o que é aquele if __name__ == "__main__":? É uma convenção do Python que significa "só rode a função main() se este arquivo foi executado diretamente (e não importado por outro arquivo)". Você vai ver isso em praticamente todo script Python sério — pode adotar como padrão desde já.

Pegadinha comum Sem o if __name__ == "__main__":, se outro arquivo Python fizer import conversor para reaproveitar a função celsius_para_fahrenheit, o programa vai executar main() automaticamente — inclusive o input() — mesmo que ninguém quisesse rodar o conversor completo naquele momento. O if __name__ evita esse efeito colateral indesejado.

Um gostinho de manipulação de dados

Antes de aprender bibliotecas especializadas, dá pra fazer bastante coisa só com listas e dicionários — as estruturas que você já conhece. Imagine uma lista de vendas: 

vendas = [
    {"produto": "Notebook", "valor": 3500, "quantidade": 2},
    {"produto": "Mouse", "valor": 50, "quantidade": 10},
    {"produto": "Teclado", "valor": 120, "quantidade": 5},
]

total_geral = 0
for venda in vendas:
    subtotal = venda["valor"] * venda["quantidade"]
    total_geral += subtotal
    print(f"{venda['produto']}: R$ {subtotal:.2f}")

print(f"Total geral: R$ {total_geral:.2f}")
Notebook: R$ 7000.00
Mouse: R$ 500.00
Teclado: R$ 600.00
Total geral: R$ 8100.00

Python também tem atalhos elegantes para transformar listas em uma linha, chamados de list comprehensions — uma forma compacta de criar uma lista nova a partir de outra: 

produtos_caros = [v["produto"] for v in vendas if v["valor"] > 100]
print(produtos_caros)   # ['Notebook', 'Teclado']

subtotais = [v["valor"] * v["quantidade"] for v in vendas]
print(subtotais)   # [7000, 500, 600]

Leia assim: "para cada v em vendas, se o valor for maior que 100, pegue o produto". É o mesmo resultado que um filter().map() encadeado em JavaScript, só que em uma sintaxe mais enxuta.

Ler e escrever arquivos CSV

CSV (valores separados por vírgula) é o formato mais comum para trocar dados tipo planilha entre sistemas. A biblioteca padrão já sabe lidar com ele: 

import csv

with open("vendas.csv", mode="r", encoding="utf-8") as arquivo:
    leitor = csv.DictReader(arquivo)
    for linha in leitor:
        print(linha["produto"], linha["valor"])

O bloco with open(...) as arquivo: é o jeito recomendado de abrir arquivos em Python: ele garante que o arquivo seja fechado automaticamente ao final do bloco, mesmo que algo dê errado no meio do caminho.

Próximos passos: pandas

Quando os dados crescem — milhares ou milhões de linhas, vindas de planilhas, bancos de dados ou APIs — listas e dicionários puros começam a ficar lentos e trabalhosos de manipular. É aí que entra o pandas, a biblioteca mais usada do mundo para análise de dados em Python. Ela organiza dados em tabelas (chamadas de DataFrames) e oferece operações prontas para filtrar, agrupar, cruzar e resumir grandes volumes de informação em poucas linhas de código.

Você não precisa aprender pandas agora — o importante nesta etapa é entender que os conceitos que você já viu (listas, dicionários, loops, condicionais) são exatamente a base sobre a qual o pandas é construído. Quando chegar a hora de mergulhar em ciência de dados, você não vai estar começando do zero: só vai estar trocando "listas de dicionários" por uma ferramenta mais poderosa para o mesmo tipo de tarefa.

Dica Para instalar bibliotecas externas como o pandas, o Python usa o gerenciador de pacotes pip (algo como o npm do JavaScript): pip install pandas. Ele baixa a biblioteca do PyPI (o repositório oficial de pacotes Python) e a deixa disponível para import nos seus scripts.

Resumo

  • Automação de tarefas repetitivas é o uso mais comum e mais valorizado de Python fora do mundo puramente técnico.
  • A biblioteca padrão (os, csv, datetime, json) já resolve boa parte das tarefas sem instalar nada.
  • Scripts de linha de comando usam input() para receber dados e a convenção if __name__ == "__main__": para evitar efeitos colaterais ao serem importados.
  • List comprehensions ([expr for item in lista if condição]) são um jeito compacto de filtrar e transformar listas.
  • with open(...) as arquivo: é a forma segura de abrir e fechar arquivos automaticamente.
  • Pandas é o próximo passo natural para trabalhar com grandes volumes de dados, construído sobre os mesmos conceitos básicos já aprendidos.
