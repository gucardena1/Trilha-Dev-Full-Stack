8. Python

Funções e orientação a objetos

De receitas reutilizáveis a "moldes" que criam objetos com dados e comportamento próprios.

Na lição anterior você viu a sintaxe básica do Python. Agora vamos organizar código de verdade: primeiro em funções (blocos reutilizáveis), depois em classes (moldes para criar objetos com estado e comportamento). Esses dois conceitos são a base de praticamente todo código Python de nível intermediário para cima.

Funções com def

Em Python, uma função é declarada com a palavra def (de "define"), seguida do nome, parênteses com os parâmetros, e dois-pontos. O corpo da função é o bloco indentado logo abaixo — de novo, a indentação é o que delimita onde a função começa e termina. 

def saudar(nome):
    return f"Olá, {nome}!"

mensagem = saudar("Carlos")
print(mensagem)   # Olá, Carlos!

Compare com o JavaScript: no lugar de function saudar(nome) { return ... }, temos def saudar(nome): seguido de um bloco indentado, sem chaves e sem ponto e vírgula.

Analogia Uma função é como uma receita de bolo escrita num cartão: tem um nome ("Bolo de cenoura"), uma lista de ingredientes que você fornece (os parâmetros) e um resultado final que ela entrega (o return). Você pode usar a mesma receita quantas vezes quiser, trocando os ingredientes, sem precisar reescrevê-la do zero cada vez.

Parâmetros: obrigatórios, com valor padrão e nomeados

Python oferece mais flexibilidade que o JavaScript na hora de definir parâmetros:

def apresentar(nome, idade=18, cidade="não informada"):
    return f"{nome}, {idade} anos, de {cidade}"

print(apresentar("Ana"))                          # usa os valores padrão
print(apresentar("Bruno", 25))                     # idade posicional
print(apresentar("Carla", cidade="Curitiba"))      # nomeado, pula "idade"
print(apresentar(nome="Davi", idade=30, cidade="Recife"))  # tudo nomeado

Parâmetros com valor padrão (idade=18) tornam-se opcionais na chamada. Argumentos nomeados (cidade="Curitiba") deixam claro o que cada valor representa, e permitem pular parâmetros intermediários — algo que o JavaScript não oferece de forma nativa sem usar um objeto.

Pegadinha comum: valores padrão mutáveis Nunca use uma lista ou dicionário vazio como valor padrão de um parâmetro: 
# ERRADO
def adicionar_item(item, lista=[]):
    lista.append(item)
    return lista

print(adicionar_item("maçã"))   # ['maçã']
print(adicionar_item("banana")) # ['maçã', 'banana'] — inesperado!
O valor padrão [] é criado uma única vez, quando a função é definida, e é reaproveitado (e alterado) em todas as chamadas seguintes. O jeito correto é usar None como padrão e criar a lista dentro da função: 
# CERTO
def adicionar_item(item, lista=None):
    if lista is None:
        lista = []
    lista.append(item)
    return lista

Retorno de múltiplos valores

Python permite devolver mais de um valor de uma função, separando por vírgula — por baixo dos panos, isso é uma tupla: 

def dividir(a, b):
    quociente = a // b   # divisão inteira
    resto = a % b        # resto da divisão
    return quociente, resto

q, r = dividir(17, 5)
print(q, r)   # 3 2

Classes: moldes para criar objetos

Uma classe é a planta baixa de um objeto: ela descreve quais dados (atributos) e quais ações (métodos) todo objeto criado a partir dela vai ter. Cada objeto criado a partir de uma classe é chamado de instância. 

class Cachorro:
    def __init__(self, nome, raca):
        self.nome = nome
        self.raca = raca

    def latir(self):
        return f"{self.nome} está latindo: Au au!"

rex = Cachorro("Rex", "Labrador")
bidu = Cachorro("Bidu", "Vira-lata")

print(rex.nome)       # Rex
print(rex.latir())    # Rex está latindo: Au au!
print(bidu.latir())   # Bidu está latindo: Au au!

__init__ é o construtor: um método especial que roda automaticamente sempre que um novo objeto é criado com Cachorro("Rex", "Labrador"). É nele que você define os atributos iniciais do objeto.

Analogia Uma classe é a fôrma de biscoito, e cada objeto criado a partir dela é um biscoito individual. Todos os biscoitos têm o mesmo formato geral (os mesmos atributos e métodos disponíveis: nome, raça, o ato de latir), mas cada um pode ter recheio ou cobertura diferente (valores próprios: "Rex", "Labrador" vs. "Bidu", "Vira-lata").

Entendendo o self

self é o parâmetro que toda função dentro de uma classe recebe automaticamente como primeiro argumento, e representa o próprio objeto que está chamando o método. É através dele que um método acessa os atributos daquele objeto específico. 

class ContaBancaria:
    def __init__(self, titular, saldo=0):
        self.titular = titular
        self.saldo = saldo

    def depositar(self, valor):
        self.saldo += valor

    def sacar(self, valor):
        if valor > self.saldo:
            print("Saldo insuficiente!")
        else:
            self.saldo -= valor

conta = ContaBancaria("Marina", 100)
conta.depositar(50)
conta.sacar(30)
print(conta.saldo)   # 120

Quando você chama conta.depositar(50), o Python "por baixo dos panos" está passando conta como o self: é como se você tivesse escrito ContaBancaria.depositar(conta, 50). Isso é o que garante que self.saldo se refira ao saldo daquela conta, e não de outra.

Dica self não é uma palavra reservada — é só uma convenção (praticamente universal) usada por todo mundo que escreve Python. Sempre inclua-o como primeiro parâmetro de qualquer método dentro de uma classe, mesmo sem precisar passá-lo manualmente na chamada.

Herança: reaproveitando classes

Herança permite criar uma classe nova a partir de outra já existente, reaproveitando seus atributos e métodos e adicionando ou sobrescrevendo o que for preciso. 

class Animal:
    def __init__(self, nome):
        self.nome = nome

    def emitir_som(self):
        return f"{self.nome} faz algum som."

class Gato(Animal):
    def emitir_som(self):
        return f"{self.nome} faz: Miau!"

class Vaca(Animal):
    def emitir_som(self):
        return f"{self.nome} faz: Muuu!"

animais = [Gato("Félix"), Vaca("Mimosa"), Animal("Bicho misterioso")]

for animal in animais:
    print(animal.emitir_som())
Félix faz: Miau!
Mimosa faz: Muuu!
Bicho misterioso faz algum som.

Gato(Animal) significa "a classe Gato herda de Animal". Gato e Vaca ganham automaticamente o __init__ de Animal (não precisaram reescrevê-lo), e cada uma sobrescreve o método emitir_som com seu próprio comportamento. Isso é chamado de polimorfismo: objetos de classes diferentes respondendo à mesma "pergunta" (emitir_som()) de formas diferentes.

Pegadinha comum Se a subclasse precisar de um __init__ próprio, mas ainda quiser aproveitar o da classe pai, use super().__init__(...) em vez de reescrever tudo: 
class Cavalo(Animal):
    def __init__(self, nome, cor):
        super().__init__(nome)  # reaproveita o __init__ do Animal
        self.cor = cor

Resumo

  • Funções são definidas com def nome(parametros):, seguidas de um bloco indentado.
  • Parâmetros podem ter valor padrão e podem ser passados por nome, tornando chamadas mais legíveis.
  • Nunca use listas ou dicionários vazios como valor padrão de parâmetro — use None e crie dentro da função.
  • Classes são moldes que definem atributos e métodos; instâncias são os objetos criados a partir delas.
  • __init__ é o construtor, e self representa o próprio objeto dentro de cada método.
  • Herança (class Filha(Mae):) reaproveita comportamento; métodos podem ser sobrescritos na subclasse.
