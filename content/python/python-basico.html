8. Python

Python básico

Uma linguagem que parece pseudocódigo de verdade: simples de ler, poderosa de usar.

Por que aprender Python depois de JavaScript?

Se você já passou pela trilha de JavaScript, boa notícia: os conceitos de fundo (variáveis, condicionais, loops, funções) são os mesmos — só muda a "sotaque" da linguagem. Python é hoje uma das linguagens mais usadas do mundo, famosa por três coisas: sintaxe limpa, uma comunidade gigante de bibliotecas prontas, e presença forte em automação, dados, inteligência artificial e backend.

Diferente do JavaScript, que nasceu para rodar dentro do navegador, o Python nasceu para rodar "no computador" mesmo: scripts, servidores, análise de dados, ciência, automação de tarefas do dia a dia. Você não escreve Python numa página HTML — você roda arquivos .py diretamente com um interpretador.

Analogia Se o JavaScript é a língua que você precisa falar para se comunicar dentro de uma loja específica (o navegador), o Python é mais como o inglês: falado em muitos lugares diferentes — automação de escritório, ciência de dados, backend de sites, scripts de sistema — cada um usando um "sotaque" (biblioteca) próprio para o seu contexto.

Rodando seu primeiro código

Um arquivo Python é só um arquivo de texto com extensão .py. Para rodar, você usa o interpretador Python no terminal: 

# arquivo: ola.py
print("Olá, mundo!")
$ python3 ola.py
Olá, mundo!

print() é a função mais básica de Python: ela exibe algo na tela. É o equivalente direto do console.log() do JavaScript.

A indentação não é estilo, é sintaxe

Aqui está a diferença mais marcante para quem vem de JavaScript, PHP ou Java: em Python, não existem chaves { } para marcar blocos de código. Quem define onde um bloco começa e termina é a indentação (os espaços no começo da linha). Isso não é uma escolha de formatação — é parte da gramática da linguagem. Se a indentação estiver errada, o código não roda. 

idade = 20

if idade >= 18:
    print("Maior de idade")
    print("Pode dirigir")
else:
    print("Menor de idade")

print("Isso roda sempre, está fora do if")

Repare que as duas linhas dentro do if têm exatamente 4 espaços de recuo (o padrão recomendado em Python). A última linha, sem recuo, não faz parte do if — ela roda de qualquer forma. Em JavaScript, o equivalente teria chaves { } para deixar isso explícito; em Python, o próprio espaço em branco cumpre esse papel.

Pegadinha comum Nunca misture espaços e tabs na mesma indentação — o Python pode reclamar de IndentationError mesmo quando visualmente parece alinhado. Configure seu editor para usar sempre 4 espaços (não tab) por nível. A maioria dos editores modernos já faz isso automaticamente para arquivos .py.

Variáveis e tipos

Criar uma variável em Python é ainda mais direto que em JavaScript: não existe let nem const, só o nome, um sinal de igual e o valor. 

nome = "Marina"       # string (texto)
idade = 28            # int (número inteiro)
altura = 1.68         # float (número com casas decimais)
ativo = True          # bool (True ou False, sempre com maiúscula)
nada = None           # equivalente ao "null"/"undefined" do JS

Python é uma linguagem de tipagem dinâmica: você não declara o tipo, ele é inferido automaticamente pelo valor. Mas, diferente do JavaScript, Python é bem mais rígido na hora de misturar tipos numa operação: 

idade = 28
print("Idade: " + idade)   # ERRO! não dá pra somar string com int direto

print("Idade: " + str(idade))  # certo: converte o número pra texto
print(f"Idade: {idade}")       # melhor ainda: f-string

A f-string (uma string com f antes das aspas) é a forma moderna e recomendada de montar textos com valores dentro, usando chaves { } — parecido com os crases (`texto ${valor}`) do JavaScript.

Dica Use type(variavel) para descobrir o tipo de algo em tempo de execução: type(idade) devolve <class 'int'>. É muito útil enquanto você está aprendendo e quer confirmar o que o Python "entendeu" do seu valor.

Listas: coleções ordenadas

A lista (list) é o equivalente do array em JavaScript: uma coleção ordenada de itens, que pode crescer, encolher e ser alterada. 

frutas = ["maçã", "banana", "uva"]

print(frutas[0])        # "maçã" — índices começam em 0, como no JS
print(len(frutas))       # 3 — quantidade de itens

frutas.append("pera")    # adiciona no final
frutas.remove("banana")  # remove pelo valor
print(frutas)             # ['maçã', 'uva', 'pera']

for fruta in frutas:
    print(fruta)

O for fruta in frutas já mostra outra marca registrada do Python: os loops são pensados para percorrer coleções diretamente, sem precisar controlar um índice manualmente (embora isso também seja possível com range(), que veremos já já).

Dicionários: pares de chave e valor

O dicionário (dict) é o equivalente ao objeto literal { } do JavaScript: guarda dados relacionados usando pares de chave: valor. 

pessoa = {
    "nome": "Ana",
    "idade": 30,
    "cidade": "São Paulo"
}

print(pessoa["nome"])          # "Ana"
pessoa["idade"] = 31            # atualiza um valor
pessoa["profissao"] = "Dev"    # adiciona uma nova chave

for chave, valor in pessoa.items():
    print(chave, "->", valor)

Uma diferença importante: em Python, acessar uma chave que não existe com pessoa["telefone"] gera um erro (KeyError), diferente do JavaScript, que devolveria undefined silenciosamente. Para acessar com segurança, use pessoa.get("telefone"), que devolve None se a chave não existir, em vez de quebrar o programa.

Pegadinha comum Python também tem tuplas — (1, 2, 3) — que parecem listas, mas são imutáveis: depois de criadas, não dá pra adicionar, remover ou alterar itens. Use lista quando a coleção vai mudar; use tupla quando ela representa um valor fixo, como coordenadas (x, y) que nunca vão ser reatribuídas.

Condicionais: if, elif, else

A estrutura é parecida com o JavaScript, com uma troca de nome: em vez de else if, Python usa elif. 

nota = 7.5

if nota >= 9:
    print("Excelente")
elif nota >= 7:
    print("Bom")
elif nota >= 5:
    print("Regular")
else:
    print("Precisa melhorar")

Os operadores de comparação são os mesmos que você já conhece: ==, !=, >, <, >=, <=. Mas os operadores lógicos são escritos por extenso, em vez de símbolos: 

idade = 25
tem_carteira = True

if idade >= 18 and tem_carteira:
    print("Pode dirigir")

if idade < 18 or not tem_carteira:
    print("Não pode dirigir")

Onde JavaScript usa &&, || e !, Python usa as palavras and, or e not.

Loops: for e while

O loop for em Python é feito para percorrer sequências. Quando você precisa de um contador numérico clássico, usa a função range(): 

for i in range(5):       # 0, 1, 2, 3, 4
    print(i)

for i in range(1, 6):    # 1, 2, 3, 4, 5
    print(i)

O while funciona de forma parecida com o JavaScript, repetindo enquanto uma condição for verdadeira:

contador = 0
while contador < 3:
    print("Rodando...", contador)
    contador += 1   # equivalente a contador = contador + 1
Dica Python não tem os operadores ++ ou -- que existem em JavaScript. Para incrementar, use contador += 1 (que também funciona com -=, *= e /=).

Resumo

  • Python roda fora do navegador: você executa arquivos .py com um interpretador, geralmente pelo terminal.
  • A indentação (espaços no início da linha) define os blocos de código — não existem chaves { }.
  • Variáveis não têm let/const: só nome, igual e valor, com tipo inferido automaticamente.
  • Listas (list) são coleções ordenadas e mutáveis; tuplas (tuple) são parecidas, mas imutáveis.
  • Dicionários (dict) guardam pares chave-valor, como os objetos { } do JavaScript.
  • elif substitui o else if, e and/or/not substituem &&/||/!.
